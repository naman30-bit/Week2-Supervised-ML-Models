This Week 2 project implements supervised machine learning for both regression and classification using Python and the Scikit-learn library. The purpose is to understand how supervised algorithms learn from labelled examples, make predictions on unseen data, and how their performance can be measured and compared. For the regression task, the built-in Scikit-learn Diabetes dataset is used to predict a continuous disease-progression measure. The data is divided into training and testing sets using an 80:20 split. Linear Regression, Decision Tree Regressor, Random Forest Regressor, and K-Nearest Neighbors Regressor are trained and evaluated. Their performance is compared using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R-squared score. For this run, Linear Regression achieved the lowest RMSE of 53.8534 and an R-squared score of 0.4526. For classification, the Breast Cancer Wisconsin dataset is used to classify cases into the dataset's two target categories. Logistic Regression, Decision Tree, Random Forest, and K-Nearest Neighbors classifiers are trained using a stratified 80:20 train-test split. StandardScaler is included in Scikit-learn Pipelines for Logistic Regression and KNN so that scaling is learned from training data only. Classification is evaluated using accuracy, precision, recall, F1-score, ROC-AUC, and a confusion matrix. Logistic Regression obtained the highest F1-score in this run (0.9861), with accuracy of 0.9825 and ROC-AUC of 0.9954. The project saves the metric comparisons as CSV files, a text classification report, a confusion matrix, and comparison graphs. The Python script is reproducible through a fixed random seed and can be executed in Visual Studio Code after installing the packages listed in requirements.txt. The results are educational model-evaluation results and are not intended for clinical diagnosis or real-world medical decision-making.
